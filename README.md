# ИНСТРУКЦИЯ ПО НАЧАЛЬНОЙ НАСТРОЙКЕ

*Все перечисленные справочники, регистры и документы доступны в подсистеме **«Добавленные объекты»**.*

---
### Общие примечания для технических специалистов
- В системе есть зачатки для работы с телеграмм ботом, а именно обработка входящих запросов, регистрация пользователей, которые обращались к боту и гиперссылка на их профили.
> Для корректной работы требуется публикация базы и белый IP. В работе бота настроен секрет ключ и регламентное задание, которое обновляет секрет.
> В справочнике **Выплата зарплаты** реализовано два окна для отображения задолжностей перед сотрудниками для удобства.




## Шаг 1. Подготовка Telegram-бота и группы

- **Создайте Telegram-бота** через @BotFather и получите токен для подключения.
- **Создайте группу** в Telegram для уведомлений, добавьте туда бота.
- **Получите chat ID** вашей группы (public — `@groupname`).
- Убедитесь, что бот может отправлять сообщения в группу.

---

## Шаг 2. Заполнение констант

- В разделе **Добавленные объекты → Сервис** заполните:
  - **«Абонентская плата»** — элемент справочника «Номенклатура» (создайте при необходимости).
  - **«Работы специалиста»** — элемент справочника «Номенклатура» (создайте при необходимости).
  - **«Токен управления ботом»** — токен Telegram-бота.
  - **«Идентификатор группы»** — chat ID группы Telegram.

---

## Шаг 3. Настройка условий оплаты сотрудников

- Откройте справочник **"Оклады и премии сотрудников сведений"**.
> Укажите для специалистов, *если это требуется* процент от заказов, для всех сотрудников — оклады.

---

## Шаг 4. Заполнение графика работы

- В справочнике **«Графики работы»** создайте нужные виды графика (например, пятидневка).
- В подсистеме **Добавленный объект → Сервис** используйте обработку **«Заполнение графика**.
  - Выберите необходимый период.
  - В поле «Выходные дни» укажите номера выходных (например, `6,7` для субботы и воскресенья).
  - Создайте элемент графика, нажмите «Заполнить».
- Проверьте корректность заполнения. Все выходные и отпуска отображаются по календарным дням.
> *Проверить корректность можно в **Функции для технических специалистов → Регистры сведений → График работы** 

---

## Шаг 5. Добавление пользователей и назначение ролей

- В справочнике **«Пользователи»** создайте отдельного пользователя для каждого сотрудника.
- На вкладке прав доступа выберите соответствующий профиль группы:
  - Для бухгалтера — **«БухгалтерИТФирмы»**.
  - Для кадровика — **«Кадровик расчетчик»**.
  - Для специалиста — **Специалист**
  - Для других сотрудников — профиль в зависимости от должности.
- Профили групп доступа заранее созданы и корректно отражают наборы ролей. Изменять их можно в справочнике **"Профили групп доступа"**.
> Более подробно ознакомиться с профилями можно в разделе:  
  **Администрирование → Настройки пользователей и прав → Профили групп доступа**

---

## Шаг 6. Первичная организация справочников и процедур

1. **Пользователи** перед началом работы должны заполнить предполагаемые даты отпусков на год **Оплата сотрудников → Отпуска**.
2. **Бухгалтер** использует обработку **«ВКМ массовое создание актов»** для автоматического формирования реализаций за месяц. В обработке указывается нужный период.
> Система информирует Бухгалтера о том сколько реализайи было создано, записано и проведенно.
> Команда **"Заполнить реализации"** заполняет реализации в документе **"Реализация товаров и услуг"**, если *"Бухгалтеру"* требуется увидеть результат заполнения, тогда следует нажать команду *"Вывести результат заполнения"*. 
> В данном окне настроена маршрутизация по документам, поэтому "Бухгалтер" может нажать дважды на поле *"Договор"* или *"Реализация"* и окно формы откроется.
3. **Менеджер** заводит договоры вида «Абонентское обслуживание» и обязательно заполняет:
   - дату начала, дату окончания,
   - стоимость часа работы,
   - сумму абонентской платы.
   Эти поля обязательны для корректной работы документов.
> **Примечание:** Если не заполнены константы **«Работы специалиста»** или **«Абонентская плата»**, автозаполнение документа реализации невозможно.

---

## Шаг 7. Проверка работоспособности и тестирование

- Запустить внешнюю обработку vanessa-automation-single.
- Проверьте создание и заполнение всех основных справочников.
- На странице запуска нажать "Открыть feuture-файл" 
- Выбрать приложенный сценарий с наименованием "Сценарий"
- Нажать кнопку в toolsbare "Выполнить" или F5
- Дождаться результата выполнения теста
